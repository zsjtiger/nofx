Crux Architecture

Feature architecture: web app, Go backend, trader cycle, external services and store

Trader cycle

  • • Runs for every running trader
  • • Decisions pass a rule check before any order
  • • Each cycle records decisions, orders and equity
  • • Trading pauses when risk control stops it

Markets and brokers

  • • US stocks: Alpaca paper account
  • • A-shares: built-in paper broker (cnpaper)
  • • Lots, T+1 and shorting rules differ by market
  • • Paper trading only

Data and security

  • • GORM over SQLite or PostgreSQL
  • • API keys encrypted at rest
  • • Login uses JWT sessions
  • • Optional browser-to-server encryption (TRANSPORT_ENCRYPTION)
